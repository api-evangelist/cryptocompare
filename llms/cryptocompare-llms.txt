# CryptoCompare (CoinDesk Data / CCData)

> Crypto market data aggregator covering 300+ exchanges, 10,000+ assets, and 300,000+ trading pairs. Two REST surfaces — the legacy min-api.cryptocompare.com and the modern data-api.cryptocompare.com (CoinDesk Data API: Spot, Index/Reference Rates, Futures, Options, News, On-Chain, Asset) — plus a WebSocket streamer at wss://streamer.cryptocompare.com/v2 and an official MCP server at https://mcp.coindesk.com/mcp. Authentication is an API key (`Authorization: Apikey {key}` header or `api_key` query parameter); the free tier was retired on 2026-05-21, so a paid subscription is required.
